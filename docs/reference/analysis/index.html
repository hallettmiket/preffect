    Clustering and figures¶

    Both need extra packages:

    pip install 'preffect[cluster]'   # grouping samples and scoring the grouping
pip install 'preffect[viz]'       # the above, plus figures

    Clustering¶

    preffect.clustering ¶

    Group samples, and measure how well the grouping recovers known labels.

    This is what the paper's subtype figures rest on, and what issues #4, #5 and

    16 need. Finding 30 established that a KL divergence cannot rank two models,¶

    because it moves under a rescaling that leaves every prediction identical. A clustering-recovery score does not move under that rescaling, which is why it is the measure those issues now ask for.

    Three things can be clustered, and version 0.1 had a separate function for each with the resolution search copied into all three:

    • the latent space, the model's summary of each sample
    • the cleaned counts, what the model predicts each sample should look like
    • the observed counts, as a baseline to beat

    Here there is one function and a choice of input, because three copies of a search is three places for it to go wrong, and in version 0.1 it had.

    Clustering needs extra packages. pip install 'preffect[cluster]'. They are kept out of the core install because fitting a model does not need them.

    @dataclass(frozen=True)
class ClusterResult:
    """A grouping of samples, and the settings that produced it."""

    #: One integer per sample, in the order the samples were given.
    labels: np.ndarray
    #: The resolution the labels were actually produced at. See ``cluster_samples``.
    resolution: float
    n_clusters: int
    source: str
    #: True when the search stopped without reaching the requested count.
    hit_the_floor: bool = False
    #: Each resolution tried and how many clusters it gave, oldest first.
    search: tuple[tuple[float, int], ...] = field(default=())

    def __post_init__(self) -> None:
        if self.labels.ndim != 1:
            raise PreffectError(
                f"labels should be one per sample, got shape {self.labels.shape}"
            )

    def __len__(self) -> int:
        return int(self.labels.shape[0])

    Lower the Leiden resolution until the grouping has few enough clusters.

    Leiden does not take a number of clusters, it takes a resolution, and coarser groupings need lower numbers. Version 0.1 searched downward from 1.0 for a resolution giving at most five clusters, which is the number of PAM50 subtypes, and this keeps that behaviour with three corrections.

    Version 0.1 reported a resolution its labels did not come from. When the search bottomed out it did this::

    elif resolution <= 0.01:
    resolution = 0.1
    break

    It set the variable and broke without re-running Leiden, so the labels still came from a resolution at or below 0.01 while 0.1 was what got recorded. Here the search returns the resolution the labels were actually produced at, and says separately whether it ran out of room.

    The steps are taken on a grid, not by repeated subtraction. Version 0.1 did resolution -= 0.1 from 1.0, which reaches 0.30000000000000004 and then 0.20000000000000004, which is not <= 0.2, so the branch meant to switch to finer steps fired one step later than intended and at a value no one would predict.

    At most, not exactly. The search only ever lowers the resolution, so it stops the moment the count is low enough and can return far fewer clusters than asked for, including one. That was true of version 0.1 too; what is new is that the result says so. target_clusters is a ceiling.

    def resolution_for_target(
    values: np.ndarray,
    *,
    target_clusters: int = 5,
    n_neighbors: int = 10,
    seed: int = 0,
    start: float = 1.0,
) -> ClusterResult:
    """Lower the Leiden resolution until the grouping has few enough clusters.

    Leiden does not take a number of clusters, it takes a resolution, and
    coarser groupings need lower numbers. Version 0.1 searched downward from 1.0
    for a resolution giving at most five clusters, which is the number of PAM50
    subtypes, and this keeps that behaviour with three corrections.

    **Version 0.1 reported a resolution its labels did not come from.** When the
    search bottomed out it did this::

        elif resolution <= 0.01:
            resolution = 0.1
            break

    It set the variable and broke *without re-running Leiden*, so the labels
    still came from a resolution at or below 0.01 while 0.1 was what got
    recorded. Here the search returns the resolution the labels were actually
    produced at, and says separately whether it ran out of room.

    **The steps are taken on a grid, not by repeated subtraction.** Version 0.1
    did ``resolution -= 0.1`` from 1.0, which reaches 0.30000000000000004 and
    then 0.20000000000000004, which is not ``<= 0.2``, so the branch meant to
    switch to finer steps fired one step later than intended and at a value no
    one would predict.

    **At most, not exactly.** The search only ever lowers the resolution, so it
    stops the moment the count is low enough and can return far fewer clusters
    than asked for, including one. That was true of version 0.1 too; what is
    new is that the result says so. ``target_clusters`` is a ceiling.

    :param values: samples by features.
    :param target_clusters: the most clusters wanted.
    :param n_neighbors: neighbours per sample when building the graph.
    :param seed: passed to Leiden, which is otherwise not repeatable.
    :param start: the first resolution tried.
    """
    import warnings

    import anndata as ad

    sc = _require_cluster_extras()

    if target_clusters < 1:
        raise PreffectError(f"target_clusters has to be at least 1, got {target_clusters}")
    values = np.ascontiguousarray(np.asarray(values, dtype=np.float32))
    if values.ndim != 2:
        raise PreffectError(f"expected samples by features, got shape {values.shape}")
    n_samples = values.shape[0]
    if n_samples < 2:
        raise PreffectError(f"clustering needs at least 2 samples, got {n_samples}")

    adata = ad.AnnData(values)
    with warnings.catch_warnings():
        warnings.simplefilter("ignore")
        # Never ask for more neighbours than there are other samples.
        sc.pp.neighbors(adata, n_neighbors=min(n_neighbors, n_samples - 1), use_rep="X")

        resolution = start
        search: list[tuple[float, int]] = []
        while True:
            sc.tl.leiden(
                adata,
                resolution=resolution,
                key_added="leiden",
                flavor="igraph",
                n_iterations=2,
                directed=False,
                random_state=seed,
            )
            labels = adata.obs["leiden"].to_numpy().astype(int)
            n_clusters = int(np.unique(labels).size)
            # The raw value, not a rounded copy of it. Rounding here made the
            # test that checks the steps land on a grid unable to fail: it read
            # back a number this line had already rounded. The grid is kept by
            # the step below, so an honest record shows it working.
            # Finding 37.
            search.append((resolution, n_clusters))

            if n_clusters <= target_clusters:
                hit_the_floor = False
                break
            if resolution <= MIN_RESOLUTION:
                # Out of room. Keep the labels this resolution produced rather
                # than reporting a resolution that was never run.
                hit_the_floor = True
                break
            # A grid, so every step lands on a value that can be written down.
            step = 0.01 if resolution <= 0.2 else 0.1
            resolution = round(max(MIN_RESOLUTION, resolution - step), 4)

    return ClusterResult(
        labels=labels,
        resolution=round(resolution, 4),
        n_clusters=n_clusters,
        source="values",
        hit_the_floor=hit_the_floor,
        search=tuple(search),
    )

    def cluster_samples(
    result,
    source: Source = "latent",
    *,
    observed: np.ndarray | None = None,
    target_clusters: int = 5,
    n_neighbors: int = 10,
    seed: int = 0,
) -> ClusterResult:
    """Cluster what a fitted model produced, or the counts it started from.

    Replaces version 0.1's ``cluster_latent_space``, ``cluster_counts`` and
    ``cluster_true_counts``, which were three copies of one procedure differing
    only in the matrix they read.

    :param result: an ``InferenceResult`` from ``preffect.inference.infer``.
    :param source: ``latent``, ``cleaned_counts``, or ``observed_counts``.
    :param observed: required for ``observed_counts``, which is the baseline
        the model is supposed to beat and is not part of the model's output.
    """
    if source == "latent":
        values = result.latent.detach().cpu().numpy()
    elif source == "cleaned_counts":
        values = result.expected_counts.detach().cpu().numpy()
    elif source == "observed_counts":
        if observed is None:
            raise PreffectError(
                "clustering the observed counts needs them passed in as "
                "`observed`; they are the input to the model, not its output"
            )
        values = np.asarray(
            observed.detach().cpu().numpy() if hasattr(observed, "detach") else observed
        )
    else:
        raise PreffectError(
            f"source should be 'latent', 'cleaned_counts' or 'observed_counts', "
            f"got {source!r}"
        )

    found = resolution_for_target(
        values,
        target_clusters=target_clusters,
        n_neighbors=n_neighbors,
        seed=seed,
    )
    return ClusterResult(
        labels=found.labels,
        resolution=found.resolution,
        n_clusters=found.n_clusters,
        source=source,
        hit_the_floor=found.hit_the_floor,
        search=found.search,
    )

    def clustering_recovery(labels, truth) -> RecoveryScores:
    """Score a grouping against labels that were known in advance.

    This is the functional measure issues #4, #5 and #16 ask for. Unlike a KL
    divergence it is unchanged by rescaling the latent space, so it compares
    two models rather than two gauges. See finding 30.

    Both scores are corrected for chance, which matters at these sizes: with
    five groups and a few hundred samples an uncorrected Rand index sits near
    0.7 for a random grouping and reads as success.

    :param labels: what the clustering produced, or a ``ClusterResult``.
    :param truth: the known group of each sample. Any labels; they are matched
        by identity, not by value, so strings are fine.
    """
    try:
        from sklearn.metrics import adjusted_mutual_info_score, adjusted_rand_score
    except ImportError as error:  # pragma: no cover - exercised by hand
        raise PreffectError(
            "scoring a clustering needs scikit-learn, which is not installed. "
            "Run: pip install 'preffect[cluster]'"
        ) from error

    found = np.asarray(labels.labels if isinstance(labels, ClusterResult) else labels)
    known = np.asarray(truth)
    if found.shape[0] != known.shape[0]:
        raise PreffectError(
            f"there are {found.shape[0]} cluster labels and {known.shape[0]} "
            f"known labels; they have to match"
        )
    if found.shape[0] == 0:
        raise PreffectError("there is nothing to score")

    return RecoveryScores(
        adjusted_rand=float(adjusted_rand_score(known, found)),
        adjusted_mutual_information=float(
            adjusted_mutual_info_score(known, found)
        ),
        n_clusters=int(np.unique(found).size),
        n_true_groups=int(np.unique(known).size),
        n_samples=int(found.shape[0]),
    )

    Figures¶

    preffect.plots ¶

    Figures for looking at what a fitted model did.

    These are diagnostics, not publication figures: they are for deciding whether a run worked. Every one returns a matplotlib Figure and none of them write a file or open a window. Saving is a separate step, so a caller chooses where things land rather than inheriting one machine's paths. Version 0.1 shipped absolute paths as defaults and they reached a published figure.

    Three things are deliberately different from version 0.1's six visualize_* methods:

    Genes are named, not counted. Version 0.1's scatter plot drew for x in range(0, 50), which is column positions 0 to 49. Gene order in the matrix is whatever the file or the gene selection produced, so the figure showed an arbitrary subset that changed when the order did, and it raised IndexError below 50 genes. Here you pass gene names, and the default is the most variable genes, which is a stated rule rather than an accident of layout.

    The UMAP is seeded. Version 0.1 built umap.UMAP(metric="cosine", n_neighbors=30) with no random_state in the one figure that goes in a paper, while seeding other UMAP calls in the same tree. UMAP is stochastic, so the same model and data gave a different picture every run.

    The figures do not reach into a model. They take what inference returned plus the counts, so a figure can be drawn from a saved result without rebuilding anything.

    Needs pip install 'preffect[viz]'.

    def save_figure(figure: Figure, path) -> None:
    """Write a figure, creating the folder if it is missing.

    Separate from drawing on purpose. A function that draws *and* saves cannot
    be used to build a panel of several, and has to be told a path it should

    def library_size_histogram(result, observed) -> Figure:
    """Observed library sizes against what the model inferred.

    The library size is the total counts in a sample. If the model's inferred
    sizes sit on top of the observed ones, it has learned the depth of
    sequencing; if they are shifted or much narrower, it has not.
    """
    figure, axes = _figure(1, 2)
    observed_totals = _as_array(observed).sum(axis=1)
    inferred_totals = _as_array(result.library_size).ravel()

    for axis, values, title, colour in (
        (axes[0][0], observed_totals, "Observed", "tab:blue"),
        (axes[0][1], inferred_totals, "Inferred by the model", "tab:orange"),
    ):
        axis.hist(values, bins=30, color=colour, edgecolor="white")
        axis.set_title(title)
        axis.set_xlabel("total counts in a sample")
        axis.set_ylabel("samples")

    # Same limits on both, or two different pictures look like the same one.
    both = np.concatenate([observed_totals, inferred_totals])
    for axis in (axes[0][0], axes[0][1]):
        axis.set_xlim(both.min(), both.max())
    return figure

    def gene_scatter(
    result,
    observed,
    *,
    gene_names: Sequence[str] | None = None,
    genes: Sequence[str] | None = None,
    n_genes: int = 12,
) -> Figure:
    """Observed against fitted counts, one panel per gene.

    A gene whose points lie on the diagonal is one the model reproduces.

    :param genes: which genes to draw, **by name**. Defaults to the most
        variable, because those are the ones a model can be wrong about. Version
        0.1 drew columns 0 to 49, which is a different set of genes every time
        the gene order changes.
    :param gene_names: names for the columns, needed to select by name.
    """
    observed_values = _as_array(observed)
    fitted = _as_array(result.expected_counts)
    if observed_values.shape != fitted.shape:
        raise PreffectError(
            f"observed counts are {observed_values.shape} and fitted are "
            f"{fitted.shape}; they have to match"
        )

    n_available = observed_values.shape[1]
    if genes is not None:
        if gene_names is None:
            raise PreffectError(
                "selecting genes by name needs `gene_names` for the columns"
            )
        lookup = {str(name): i for i, name in enumerate(gene_names)}
        missing = [g for g in genes if str(g) not in lookup]
        if missing:
            raise PreffectError(
                f"these genes are not in the data: {', '.join(map(str, missing[:5]))}"
            )
        chosen = np.array([lookup[str(g)] for g in genes])
    else:
        chosen = _most_variable(observed_values, min(n_genes, n_available))

    columns = min(4, len(chosen))
    rows = int(np.ceil(len(chosen) / columns))
    figure, axes = _figure(rows, columns, size=(3.0, 3.0))

    for position, column in enumerate(chosen):
        axis = axes[position // columns][position % columns]
        axis.scatter(observed_values[:, column], fitted[:, column], s=8, alpha=0.6)
        limit = max(observed_values[:, column].max(), fitted[:, column].max(), 1.0)
        axis.plot([0, limit], [0, limit], linestyle="--", linewidth=1, color="grey")
        label = str(gene_names[column]) if gene_names is not None else f"column {column}"
        axis.set_title(label, fontsize=9)
        axis.set_xlabel("observed")
        axis.set_ylabel("fitted")

    for empty in range(len(chosen), rows * columns):  # blank any unused panels
        axes[empty // columns][empty % columns].axis("off")
    return figure

    def batch_adjustment(result, observed, batches) -> Figure:
    """Per-gene means of one batch against another, observed and fitted.

    If batch correction worked, the fitted panel is closer to the diagonal than
    the observed one: the model has removed a difference that was in the data.
    Every pair of batches is drawn, capped at the first ``MAX_BATCHES`` because
    the number of pairs grows as the square.
    """
    observed_values = _as_array(observed)
    fitted = _as_array(result.expected_counts)
    labels = _as_array(batches).ravel()
    if labels.shape[0] != observed_values.shape[0]:
        raise PreffectError(
            f"there are {labels.shape[0]} batch labels and "
            f"{observed_values.shape[0]} samples; they have to match"
        )

    present = list(dict.fromkeys(labels.tolist()))[:MAX_BATCHES]
    pairs = [(a, b) for i, a in enumerate(present) for b in present[i + 1 :]]
    if not pairs:
        raise PreffectError(
            f"batch comparison needs at least two batches, found {len(present)}"
        )

    figure, axes = _figure(len(pairs), 2, size=(4.0, 3.6))
    for row, (first, second) in enumerate(pairs):
        for column, (values, title) in enumerate(
            ((observed_values, "Observed"), (fitted, "Fitted"))
        ):
            axis = axes[row][column]
            x = values[labels == first].mean(axis=0)
            y = values[labels == second].mean(axis=0)
            axis.scatter(x, y, s=6, alpha=0.5)
            limit = max(x.max(), y.max(), 1.0)
            axis.plot([0, limit], [0, limit], linestyle="--", linewidth=1, color="grey")
            axis.set_title(f"{title}: batch {first} against {second}", fontsize=9)
            axis.set_xlabel(f"mean count, batch {first}")
            axis.set_ylabel(f"mean count, batch {second}")
    return figure

    deterministic. On a vignette this is invisible. On 528 samples it is worth
    knowing before you wonder why the figure is slow, and it is the trade this

    time it saved.

    ``draw_umap_with_subtype``: they differed only in what coloured the points.

        import umap
    except ImportError as error:  # pragma: no cover - exercised by hand
        raise PreffectError(
            "the UMAP figure needs umap-learn, which is not installed. "
            "Run: pip install 'preffect[viz]'"
        ) from error

        metric=metric,
        # Never ask for more neighbours than there are other samples. Version
        # 0.1 hardcoded 30 and failed on any cohort smaller than that.
        n_neighbors=min(n_neighbors, n_samples - 1),
        random_state=seed,

    figure, axes = _figure(size=(5.5, 4.5))
    axis = axes[0][0]

        axis.scatter(embedding[:, 0], embedding[:, 1], s=14, alpha=0.8)
    else:

        if labels.shape[0] != n_samples:
            raise PreffectError(
                f"there are {labels.shape[0]} labels and {n_samples} samples; "
                f"they have to match"
            )
        for value in dict.fromkeys(labels.tolist()):
            rows = labels == value
            axis.scatter(
                embedding[rows, 0], embedding[rows, 1], s=14, alpha=0.8, label=str(value)
            )
        axis.legend(title=colour_label, fontsize=8, title_fontsize=9)

    axis.set_ylabel("UMAP 2")

        f"Latent space, UMAP (seed {seed}, {metric} distance)", fontsize=10
    )
    return figure

        raise PreffectError(
            f"only {len(positions)} of {len(gene_set)} {gene_set.name} genes are "
            f"in this data, which is below min_genes={min_genes}. Tried both "
            f"gene symbols and Ensembl identifiers. Check that the gene names "
            f"are what you think they are: this data names its first gene "
            f"{str(gene_names[0])!r}."
        )

    matrix = matrix[:, positions]
    if normalise == "z_score":
        spread = matrix.std(axis=0)
        scaled = (matrix - matrix.mean(axis=0)) / np.where(spread > 0, spread, 1.0)
    elif normalise == "log_z_score":
        logged = np.log1p(np.clip(matrix, 0, None))
        spread = logged.std(axis=0)
        scaled = (logged - logged.mean(axis=0)) / np.where(spread > 0, spread, 1.0)
    elif normalise == "min_max":
        low, high = matrix.min(axis=0), matrix.max(axis=0)
        scaled = (matrix - low) / np.where(high > low, high - low, 1.0)
    else:
        raise PreffectError(
            f"normalise should be 'z_score', 'log_z_score' or 'min_max', "
            f"got {normalise!r}"
        )

    groups = _ordered_groups(labels, subtype_order)
    row_order = np.concatenate([np.flatnonzero(labels == group) for group in groups])
    scaled = scaled[row_order]

    import matplotlib as mpl

    # A colour per subtype from a colormap, so any number of them works.
    palette = mpl.colormaps["tab10"].resampled(max(len(groups), 1))
    colour_of = {group: palette(i) for i, group in enumerate(groups)}

    from matplotlib.figure import Figure

    # Built by hand rather than through _figure, because the subtype bar is a
    # thin strip beside the heatmap, not a panel of equal width.
    figure = Figure(
        figsize=(max(8.0, 0.22 * len(found) + 4.0), 7.0), layout="constrained"
    )
    bar, main = figure.subplots(
        1, 2, gridspec_kw={"width_ratios": [1, 28], "wspace": 0.02}
    )

    bar.imshow(
        np.array([[colour_of[group] for group in labels[row_order]]]).transpose(1, 0, 2),
        aspect="auto",
        interpolation="nearest",
    )
    bar.set_xticks([])
    bar.set_yticks([])
    bar.set_ylabel(f"{len(row_order)} samples, grouped by subtype")

    limit = float(np.abs(scaled).max()) if normalise != "min_max" else 1.0
    image = main.imshow(
        scaled,
        aspect="auto",
        cmap="RdBu_r" if normalise != "min_max" else "hot",
        vmin=-limit if normalise != "min_max" else 0.0,
        vmax=limit,
        interpolation="nearest",
    )
    main.set_xticks(range(len(found)))
    main.set_xticklabels(found, rotation=90, fontsize=6)
    main.set_yticks([])
    main.set_title(f"{title} ({len(found)} genes matched by {naming}, {normalise})",
                   fontsize=10)

    figure.colorbar(image, ax=main, shrink=0.6, label=normalise.replace("_", " "))
    main.legend(
        handles=[
            mpl.patches.Patch(
                color=colour_of[group],
                label=f"{group} ({int((labels == group).sum())})",
            )
            for group in groups
        ],
        loc="center left",
        bbox_to_anchor=(1.18, 0.5),
        fontsize=8,
        title="subtype",
        title_fontsize=9,
    )
    return figure
