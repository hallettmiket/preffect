    Training, checkpoints and inference¶

    The objective¶

    Built as one list of named terms, so the total and the divisor cannot disagree about which terms are in play. That disagreement is the defect that started this rewrite.

    preffect.loss ¶

    The objective, assembled as a list of named terms.

    The model is trained by making one number small. That number is a weighted average of several terms, each measuring a different kind of error.

    Why a list¶

    Version 0.1 built the objective as a hand-written sum of named variables, and kept a second, separate hand-written list of weights to divide it by. The two disagreed. The library size reconstruction term was computed, multiplied by its weight, written to the log and to the printed table, and then left out of the sum, while its weight of 100 per tissue stayed in the divisor. Separately, the divisor for a simple model counted 100.1 of weight for adjacency terms a simple model does not have.

    Here the terms are collected into one list and both the numerator and the divisor are computed from that list. A term in the list contributes to both. A term not in the list contributes to neither. They cannot disagree about which terms exist, because there is only one answer to that question.

    This does not make every mistake impossible. A term can still compute the wrong quantity, or be given a silly weight. Those are different mistakes, and tests are what catch them.

    The terms¶
    • expression_recon: how surprised the fitted distribution is by the counts actually observed. The main term. Negative log-likelihood, summed over genes and averaged over samples.
    • expression_kl: how far the latent summary of each sample has drifted from a standard Gaussian. This is what keeps the latent space usable rather than letting the model memorise each sample separately.
    • library_recon: how far the predicted library size is from the observed one. Present only when the library size is being inferred.
    • library_kl: the same drift penalty for the library latent space.
    • batch_centroid: an optional penalty pulling samples from the same batch together in the latent space.
    • adjacency_recon: how well the sample-sample network is reproduced. Graph models only.
    • adjacency_kl: the drift penalty for the network's own latent space. Graph models only.
    Rows padded in for a missing tissue count towards some terms and not others¶

    The full model can be given a cohort where some patients lack one of the tissues. The missing profile is padded in as a row of per-gene means, and which terms that row belongs in is a decision version 0.1 made and version 0.2 inherited: it belongs in the latent and network terms and not in the three terms that read the counts. compute_loss takes real_rows for this, and a cohort with nothing padded passes None and is unaffected to the last bit. :mod:preffect.data.tissues has the rules and the decision record of 2026-11-02 has the measurement.

    The network term is balanced¶

    These networks are sparse, 0.2 to 8 per cent of possible pairs, so a plain mean over every pair is mostly "no edge here". Version 0.1 carried settings for weighting present against absent edges and left both at one, and under that term the network half of the model learns nothing. Measured in exp/17 on synthetic data with a known network, six seeds: the decoder settles on predicting no edge anywhere, the network latent collapses onto its prior, and the term sits at ln 2, in every run. With the linked pairs given the same total weight as the absent ones, the predicted network ranks the true edges as well as a predictor that knows the sample groups, and the expression half of the model is within noise of what it was.

    That has happened on one dataset and on neither of the two since. On the DCIS cohort at 773 genes, exp/17's run of 2026-11-02 found every arm ending with the decoder predicting exactly one half for every pair and the network latent on its prior, so balancing is neither better nor worse than the plain mean there. On dataset_full_1, exp/18 found every decoder predicting no edge anywhere under this term, which is the outcome it exists to prevent. The term is left on because nothing measured is worse under it; read the claim above as a result on one synthetic network rather than as a property of the term.

    LossWeights.edge_balance chooses how the pairs are scored and :func:network_term computes it. The default is "balanced"; "none" is the old term, kept for repeating any graph-model result produced before 2026-10-30. A third way, scoring the linked pairs against as many absent pairs drawn at random as graph autoencoders do, recovered the network about as well at more cost and collapsed once where the balanced term never did; it lost, so by the rule in exp/README.md it lives in exp/17 and not here. Decision of 2026-10-30 on weighting the network term, which closed issue #13.

    def gaussian_kl_divergence(
    mean: torch.Tensor, log_variance: torch.Tensor
) -> torch.Tensor:
    """Distance from a standard Gaussian, per sample.

    Measures how far the distribution the encoder produced for a sample has
    moved from the standard Gaussian the model assumes before seeing anything.
    Zero when they match.

    :returns: one value per sample, summed over the latent dimensions.
    """
    return -0.5 * torch.sum(
        1 + log_variance - mean.pow(2) - log_variance.exp(), dim=-1
    )

    def compute_loss(
    output: ModelOutput,
    counts: torch.Tensor,
    weights: LossWeights,
    delays: LossDelays | None = None,
    epoch: int = 1,
    batch_labels: torch.Tensor | None = None,
    network: torch.Tensor | None = None,
    real_rows: torch.Tensor | None = None,
) -> Loss:
    """Build the objective for one batch.

    :param output: what the model produced.
    :param counts: the counts to score against. During training with masking
        this is the unmasked original, so the model is judged on what it should
        have recovered rather than on what it was shown.
    :param epoch: counted from 1, used against the delays.
    :param batch_labels: required only when the batch centroid term is active.
    :param network: the observed sample-sample network for this batch, as a
        square 0/1 matrix. Supplied for the graph models, absent otherwise, in
        which case the two network terms are not in the objective at all.
    :param real_rows: which rows of ``counts`` are real samples, when the full
        model's data has rows padded in for patients missing a tissue. The
        three terms that read the counts are then averaged over those rows
        only: the expression reconstruction, and the two library-size terms.
        The latent and network terms are averaged over every row, padding
        included. Leave it None, which is what the simple and single models
        always pass, and every term is averaged over every row as before, to
        the last bit. See :mod:`preffect.data.tissues`.
    :raises ConfigError: if ``real_rows`` selects nothing, which means every
        row of this batch is padding and the counts terms have nothing to
        average. Version 0.1 averaged over nothing and produced a loss that
        was not a number; a larger batch size, or dropping the patients who
        are missing a tissue, is what to do instead.
    """
    delays = delays or LossDelays()
    if epoch < 1:
        raise ConfigError(f"epochs count from 1, got {epoch}")
    if real_rows is not None and not bool(real_rows.any()):
        raise ConfigError(
            f"every one of this batch's {real_rows.shape[0]} rows is padding, "
            f"added for a patient missing the predicted tissue, so the "
            f"expression and library terms have nothing to average over. Use a "
            f"larger batch size so that every batch holds a real sample, or "
            f"drop the patients who are missing that tissue."
        )

    terms: list[LossTerm] = []

    def over_real(value: torch.Tensor) -> torch.Tensor:
        """One value per row, averaged over the real rows of this batch."""
        return value.mean() if real_rows is None else value[real_rows].mean()

    def add(name: str, value: torch.Tensor, weight: float) -> None:
        if delays.active_at(name, epoch):
            terms.append(LossTerm(name=name, value=value, weight=weight))

    # The main term: surprise at the counts actually seen, summed across genes
    # so that a sample with more genes expressed is not penalised for it, then
    # averaged across the real samples.
    add(
        "expression_recon",
        over_real(-output.counts.log_prob(counts).sum(dim=-1)),
        weights.expression_recon,
    )

    # Over every row, padding included. Version 0.1 commented out the lines
    # that would have taken the padded rows out of this term and out of the
    # network terms below, and left a note beside the call saying ghost rows
    # "shouldn't be considered in the loss functions (except its ok for the
    # adjacency graphs)". The decision of 2026-11-02 inherits that as it
    # stands and measures it.
    add(
        "expression_kl",
        gaussian_kl_divergence(output.latent_mean, output.latent_log_variance).mean(),
        weights.expression_kl[0],
    )

    # Library terms exist only when the library size is being inferred. When it
    # is read from the data there is nothing to reconstruct and nothing to
    # regularise, so the terms are absent rather than present and zero. That
    # distinction is the point: version 0.1 kept their weights in the divisor
    # while their values were identically zero.
    if output.infers_library_size:
        observed_log = torch.log(counts.sum(dim=1, keepdim=True) + 1)
        predicted_log = output.predicted_log_library_size
        if real_rows is not None:
            observed_log = observed_log[real_rows]
            predicted_log = predicted_log[real_rows]
        add(
            "library_recon",
            torch.nn.functional.mse_loss(predicted_log, observed_log),
            weights.library_recon[0],
        )
        add(
            "library_kl",
            over_real(
                gaussian_kl_divergence(
                    output.library_latent_mean, output.library_latent_log_variance
                )
            ),
            weights.library_kl[0],
        )

    # Present only for the graph models. Absent, not zero, for the rest: a term
    # that does not apply should not be in the divisor either.
    if network is not None and getattr(output, "predicted_network", None) is not None:
        # One term per tissue, each carrying that tissue's own weight. Version
        # 0.1 stacked them and paired the stack against the weight list with
        # zip, which silently dropped a tissue when the list was short; that is
        # finding 4. Here a tissue that is present has a named term and a
        # weight of its own, and the divisor follows from the list.
        networks = network if isinstance(network, (list, tuple)) else [network]
        predicted = output.predicted_network
        predicted = predicted if isinstance(predicted, (list, tuple)) else [predicted]
        net_means = output.network_latent_mean
        net_means = net_means if isinstance(net_means, (list, tuple)) else [net_means]
        net_vars = output.network_latent_log_variance
        net_vars = net_vars if isinstance(net_vars, (list, tuple)) else [net_vars]

        if not (len(networks) == len(predicted) == len(net_means)):
            raise ConfigError(
                f"got {len(networks)} observed network(s) but {len(predicted)} "
                f"predicted and {len(net_means)} network latent space(s)"
            )
        weights.check_tissue_count(len(networks))

        suffix = (lambda i: "") if len(networks) == 1 else (lambda i: f"_{i + 1}")
        for i, (observed, guess) in enumerate(zip(networks, predicted, strict=True)):
            add(
                f"adjacency_recon{suffix(i)}",
                network_term(guess, observed, weights.edge_balance),
                weights.adjacency_recon[i],
            )
            add(
                f"adjacency_kl{suffix(i)}",
                gaussian_kl_divergence(net_means[i], net_vars[i]).mean(),
                weights.adjacency_kl[i],
            )

    if batch_labels is not None:
        add(
            "batch_centroid",
            _batch_centroid_penalty(output.latent, batch_labels),
            weights.batch_centroid[0],
        )

    if not terms:
        raise ConfigError(
            f"no loss term is active at epoch {epoch}, so there is nothing to "
            f"train on. Check the delays: every one of them starts later than "
            f"this epoch."
        )

    weighted_sum = torch.stack([term.weighted for term in terms]).sum()
    divisor = sum(term.weight for term in terms)
    total = weighted_sum / divisor if weights.normalise_by_weight_sum else weighted_sum

    return Loss(
        total=total,
        terms=tuple(terms),
        normalised=weights.normalise_by_weight_sum,
    )

    network_term(
    predicted: Tensor,
    observed: Tensor,
    edge_balance: str = "none",

    How far a predicted sample-sample network is from the observed one, for one batch.

    Binary cross-entropy between the predicted edge probabilities and the observed 0/1 network, both square over the samples in the batch. The edge_balance setting of :class:~preffect.config.LossWeights says which pairs are scored and with what weight, one of two ways:

    • "balanced", the default: every pair off the diagonal, with each linked pair weighted by the number of absent pairs per linked pair in this batch, so the linked and the absent pairs carry half the weight each. Divided by the total weight, so it is a weighted mean on the same scale as "none": a model that predicts one half everywhere scores ln 2 in both.
    • "none": the plain mean over every entry of the matrix, the diagonal included, as version 0.1 scored it. On a network 1 per cent dense that is 99 parts "no edge here" to one part "edge here", and under it the network half of the model learns nothing (exp/17). Kept for repeating a result produced before 2026-10-30.

    The balanced mode leaves the diagonal out. A sample's link to itself is not a pair, the observed network never carries one (the loader drops self-links), and the decoder scores it by the inner product of a vector with itself, which is never below one half, so scoring it against zero can only push the decoder towards predicting one half everywhere. A batch with no linked pair has nothing to balance against and scores its absent pairs as a plain mean; a batch of one sample has no pair at all and scores as "none" does.

    def network_term(
    predicted: torch.Tensor, observed: torch.Tensor, edge_balance: str = "none"
) -> torch.Tensor:
    """How far a predicted sample-sample network is from the observed one, for one batch.

    Binary cross-entropy between the predicted edge probabilities and the
    observed 0/1 network, both square over the samples in the batch. The
    ``edge_balance`` setting of :class:`~preffect.config.LossWeights` says
    which pairs are scored and with what weight, one of two ways:

    - ``"balanced"``, the default: every pair off the diagonal, with each
      linked pair weighted by the number of absent pairs per linked pair in
      this batch, so the linked and the absent pairs carry half the weight
      each. Divided by the total weight, so it is a weighted mean on the same
      scale as ``"none"``: a model that predicts one half everywhere scores
      ln 2 in both.
    - ``"none"``: the plain mean over every entry of the matrix, the diagonal
      included, as version 0.1 scored it. On a network 1 per cent dense that
      is 99 parts "no edge here" to one part "edge here", and under it the
      network half of the model learns nothing (``exp/17``). Kept for
      repeating a result produced before 2026-10-30.

    The balanced mode leaves the diagonal out. A sample's link to itself is
    not a pair, the observed network never carries one (the loader drops
    self-links), and the decoder scores it by the inner product of a vector
    with itself, which is never below one half, so scoring it against zero can
    only push the decoder towards predicting one half everywhere. A batch with
    no linked pair has nothing to balance against and scores its absent pairs
    as a plain mean; a batch of one sample has no pair at all and scores as
    ``"none"`` does.

    :param predicted: edge probabilities, ``[samples, samples]``.
    :param observed: the network for the same samples as a 0/1 matrix.
    :raises ConfigError: for an ``edge_balance`` that is not one of the two.
    """
    guess = predicted.clamp(1e-7, 1 - 1e-7)
    if edge_balance == "none":
        return torch.nn.functional.binary_cross_entropy(guess, observed)
    if edge_balance not in LossWeights.EDGE_BALANCE_MODES:
        raise ConfigError(
            f"edge_balance must be one of {list(LossWeights.EDGE_BALANCE_MODES)}, "
            f"got {edge_balance!r}"
        )
    if guess.shape != observed.shape or guess.dim() != 2 or guess.shape[0] != guess.shape[1]:
        raise ConfigError(
            f"the predicted network is shaped {tuple(guess.shape)} and the observed "
            f"one {tuple(observed.shape)}; both must be square over the same samples"
        )

    per_pair = torch.nn.functional.binary_cross_entropy(guess, observed, reduction="none")
    n = observed.shape[0]
    off_diagonal = ~torch.eye(n, dtype=torch.bool, device=observed.device)
    present = (observed > 0) & off_diagonal
    absent = (observed <= 0) & off_diagonal
    n_present = int(present.sum())
    n_absent = int(absent.sum())
    if n_present == 0 or n_absent == 0:
        pairs = off_diagonal if n > 1 else torch.ones_like(off_diagonal)
        return per_pair[pairs].mean()

    weight = absent.float() + (n_absent / n_present) * present.float()
    return (per_pair * weight).sum() / weight.sum()

    Training¶

    preffect.training ¶

    Fitting a model, and recording honestly what happened while it fitted.

    The number this module exists to get right¶

    An epoch's loss is the mean over its batches. Version 0.1 computed the training loss that way and the validation loss a different way: it divided the accumulated validation loss by the number of tissues, which is one for the simple and single models, so the figure it printed, plotted, sent to TensorBoard and compared against for early stopping was a sum presented as a mean.

    That makes it incomparable across batch sizes, because the number of batches changes with the batch size. On four of version 0.1's own run directories, differing only in epochs and batch size, the reported values spanned 33% and the corrected values 4.4%, and the two orderings disagreed.

    Here both splits go through the same function, which divides by the number of batches it actually ran, and that count is recorded alongside the loss so the arithmetic can be checked after the fact rather than trusted.

    Early stopping¶

    Off unless asked for. It watches the validation loss and stops when it has not improved by more than a stated amount for a stated number of epochs in a row, restoring the weights from the best epoch. With no validation data it watches the training loss instead and says so, because stopping early on the training loss is a different and weaker thing.

    """The device a run will use, refused by name if the machine lacks it.

            f"device is {runtime.device!r} but this machine has no usable CUDA "

            f"device(s), numbered 0 to {count - 1}."

    def run_epoch(
    model: nn.Module,
    data: TensorData | MultiTissueData,
    config: PreffectConfig,
    epoch: int,
    optimiser: torch.optim.Optimizer | None = None,
    rng: np.random.Generator | None = None,
) -> SplitResult:
    """One pass over one split.

    Training and validation share this function deliberately. Version 0.1 wrote
    the two passes out separately, and they drifted: the validation one divided
    by the wrong thing.

    :param data: one split for the simple and single models, or several
        matched tissues for the full model. The two are told apart by type
        rather than by asking a batch what it carries: asking is what stopped
        every full-model run at its first batch (finding 55).
    :param optimiser: supply it to learn, omit it to only measure.
    """
    learning = optimiser is not None
    model.train(learning)

    batches = batch_indices(
        data.n_samples,
        config.train.batch_size,
        rng=rng,
        shuffle=learning and rng is not None,
        drop_last=config.train.drop_last_batch if learning else False,
    )
    if not batches:
        raise ConfigError(
            f"a split of {data.n_samples} samples produced no batches at a batch "
            f"size of {config.train.batch_size}"
        )

    running_total = 0.0
    running_terms: dict[str, float] = {}
    gradient_norms: list[float] = []
    largest_update = 0.0

    seen_latents: list[torch.Tensor] = []
    with torch.set_grad_enabled(learning):
        for index, positions in enumerate(batches):
            part = data.select(positions)
            # The library-size correction for this batch's rows, None when
            # nothing is hidden. Without it a masked batch is scaled by a total
            # short by the hidden fraction while its targets are not, which is
            # finding 56.
            if isinstance(part, MultiTissueData):
                # Several matched tissues: the model takes the list of counts,
                # the target tissue's corrections and one network per tissue,
                # and predicts the target tissue alone. The same shape ``infer``
                # uses on the same data. Until 2026-11-02 this branch did not
                # exist and the loop asked every batch ``has_network``, which a
                # multi-tissue batch does not answer, so the full model stopped
                # at its first batch and had never been trained. Finding 55.
                output = model(
                    [t.inputs for t in part.tissues],
                    part.target.corrections,
                    [t.edge_index for t in part.tissues],
                    library_scale=part.target.library_scale,
                )
                # One observed network per tissue. compute_loss takes a list
                # and gives each tissue its own named term and weight.
                network = [t.adjacency_matrix() for t in part.tissues]
                targets = part.target.targets
                # Which of this batch's rows are real samples, when some
                # patients were missing the predicted tissue and had a row
                # padded in. None when none were, so a complete cohort is
                # scored exactly as it was before padding existed.
                real_rows = part.target_real_rows()
            elif part.has_network:
                output = model(
                    part.inputs,
                    part.corrections,
                    part.edge_index,
                    library_scale=part.library_scale,
                )
                network = part.adjacency_matrix()
                targets = part.targets
                real_rows = None
            else:
                output = model(
                    part.inputs, part.corrections, library_scale=part.library_scale
                )
                network = None
                targets = part.targets
                real_rows = None

            loss = compute_loss(
                output,
                targets,
                weights=config.loss,
                delays=config.delays,
                epoch=epoch,
                batch_labels=None,
                network=network,
                real_rows=real_rows,
            )

            if learning:
                optimiser.zero_grad(set_to_none=True)
                loss.total.backward()
                gradient_norms.append(_gradient_norm(model, config.train.gradient_clip_norm))
                last_step = index == len(batches) - 1
                if last_step:
                    tracked = [p for p in model.parameters() if p.grad is not None]
                    before = [p.detach().clone() for p in tracked]
                optimiser.step()
                if last_step:
                    pairs = zip(tracked, before, strict=True)
                    largest_update = max(
                        (float((p.detach() - b).abs().max()) for p, b in pairs), default=0.0
                    )

            seen_latents.append(_latent_means(output))
            running_total += float(loss.total.detach())
            for name, value in loss.named_values().items():
                running_terms[name] = running_terms.get(name, 0.0) + value

    n = len(batches)
    active, rms, latent_dim = _latent_health(seen_latents)
    return SplitResult(
        active_latent_units=active,
        latent_rms=rms,
        latent_dim=latent_dim,
        largest_gradient_norm=max(gradient_norms, default=0.0),
        mean_gradient_norm=sum(gradient_norms) / len(gradient_norms) if gradient_norms else 0.0,
        largest_update=largest_update,
        mean_loss=running_total / n,
        mean_terms={name: total / n for name, total in running_terms.items()},
        n_batches=n,
        n_samples=sum(len(b) for b in batches),
    )

    def train(
    model: nn.Module,
    train_data: TensorData | MultiTissueData,
    config: PreffectConfig,
    validation_data: TensorData | MultiTissueData | None = None,
    on_epoch=None,
) -> TrainingHistory:
    """Fit a model.

    :param train_data: one split for the simple and single models, or several
        matched tissues for the full model.
    :param on_epoch: called with each :class:`EpochRecord` as it is completed,
        for progress reporting. Reporting is the caller's business; this
        function does not print.
    """
    # The weights were drawn when the model was built, at whatever thread count
    # was in force then. Setting the count now changes nothing about them, but
    # a model built under one count and trained under another is not the model
    # a second call in the same process would build: initialisation sums floats
    # in a different order at a different count, and on this objective that
    # last-bit difference can grow into a different model (issues #22, #23).
    # Nothing can be re-drawn here, so say so, once, naming both counts.
    wanted = config.runtime.num_threads
    if wanted is not None and wanted != torch.get_num_threads():
        warnings.warn(
            f"the model was built while PyTorch was using {torch.get_num_threads()} "
            f"thread(s) and this run will use {wanted}. Starting weights drawn at "
            f"different thread counts differ in their last bits, and on this "
            f"objective that can grow into a different model, so this run may not "
            f"match one where configure_runtime(config) was called before the model "
            f"was built. Call it first. Issue #23.",
            RuntimeWarning,
            stacklevel=2,
        )

    configure_runtime(config)
    rng = np.random.default_rng(config.runtime.seed)

    # Everything moves to the requested device here, in one place, so that a
    # run which asked for a GPU runs on one. Until finding 45 nothing did, and
    # ``device="cuda"`` trained on the CPU without saying so.
    device = resolve_device(config.runtime)
    model.to(device)
    train_data = train_data.to(device)
    if validation_data is not None:
        validation_data = validation_data.to(device)

    # Only the parameters that are actually being trained. Normally that is all
    # of them; after ``preffect.pretraining.load_pretrained`` froze part of the
    # model it is not. Handing frozen parameters to Adam is harmless but wastes
    # memory on their moment estimates and makes the optimiser's record of what
    # it is training disagree with the model's.
    trainable = [p for p in model.parameters() if p.requires_grad]
    if not trainable:
        raise ConfigError(
            "every parameter in this model is frozen, so there is nothing to "
            "train. Freeze fewer parts, or load the weights without freezing."
        )
    optimiser = torch.optim.Adam(
        trainable,
        lr=config.train.learning_rate,
        weight_decay=config.train.weight_decay,
    )

    history = TrainingHistory(watched=config.train.stop_on)
    watching_loss = config.train.stop_on == "loss" and config.train.uses_early_stopping
    if watching_loss and validation_data is None:
        history.watched_training_loss = True
    if config.train.stop_on == "imputation" and isinstance(train_data, MultiTissueData):
        # Named rather than left to fall through the message below, which
        # would tell someone to hide entries in data where hiding them is not
        # built. ``workflow.hide_entries`` refuses the same thing in the same
        # terms.
        raise ConfigError(
            "stop_on='imputation' watches the error on entries hidden from the "
            "model, and this is the full model's data: one table per tissue, with "
            "hiding entries across them not built. Stop on the loss, or fit one "
            "tissue with the single model and hide entries there."
        )
    if config.train.stop_on == "imputation" and getattr(train_data, "mask", None) is None:
        raise ConfigError(
            "stop_on='imputation' watches the imputation error on the entries hidden "
            "from the model, and this training data hides none. Hide some "
            "(TensorData(..., mask=mcar_mask(...)) in Python, --hide on the command "
            "line), or stop on the loss."
        )

    best_loss = float("inf")
    best_state: dict | None = None
    epochs_without_improvement = 0

    for epoch in range(1, config.train.epochs + 1):
        train_result = run_epoch(model, train_data, config, epoch, optimiser, rng)
        validation_result = (
            None
            if validation_data is None
            else run_epoch(model, validation_data, config, epoch)
        )
        if config.train.stop_on == "imputation":
            train_result = replace(
                train_result, imputation_error=hidden_entry_error(model, train_data)
            )

        record = EpochRecord(epoch=epoch, train=train_result, validation=validation_result)
        history.epochs.append(record)

        # Say it while it is happening. A collapsed latent carries nothing
        # about which sample is which, so everything downstream of it is
        # describing noise, and the loss does not show it: the expression
        # terms carry on falling. Found by measuring after the fact, which is
        # the hard way. Finding 41.
        if record.train.latent_collapsed and not history.latent_collapsed:
            history.latent_collapsed = True
            history.first_collapsed_epoch = record.epoch
            warnings.warn(
                f"the latent space collapsed at epoch {record.epoch}: none of "
                f"its {record.train.latent_dim} dimensions vary between "
                f"samples any more, so it carries no information about which "
                f"sample is which. The loss will keep falling regardless. "
                f"Consider a KL warm-up through LossDelays, or a lower "
                f"learning rate. See issue #20.",
                stacklevel=2,
            )
        if on_epoch is not None:
            on_epoch(record)

        watched = record.watched_value(config.train.stop_on)
        if watched < best_loss - config.train.early_stopping_min_delta:
            best_loss = watched
            history.best_epoch = epoch
            epochs_without_improvement = 0
            if config.train.uses_early_stopping:
                best_state = copy.deepcopy(model.state_dict())
        else:
            epochs_without_improvement += 1

        if (
            config.train.uses_early_stopping
            and epochs_without_improvement >= config.train.early_stopping_patience
        ):
            history.stopped_early = True
            if best_state is not None:
                model.load_state_dict(best_state)
            break

    return history

    Checkpoints¶

    preffect.checkpoint ¶

    Saving and reloading a fitted model.

    A checkpoint holds tensors and settings, never a pickled Python object.

    Version 0.1 saved a session with torch.save(self), pickling the whole live object: the model, the optimiser, the datasets and the settings together. PyTorch 2.6 changed torch.load to refuse pickled objects by default, so every session version 0.1 ever wrote becomes unreadable the moment anyone upgrades. The warning announcing that change was suppressed in version 0.1 rather than acted on.

    Pickling the live object had two further costs. The file carried the training data, so a checkpoint of a small model on a large cohort was enormous and quietly contained the cohort. And it carried whatever layers the model had allocated and never used, which for a simple model was 94% of the encoder.

    Here a checkpoint is a plain dictionary of tensors and plain values. It loads under PyTorch's safe default, it does not contain anybody's data, and it can be read by a version of the code that is not the one that wrote it, because the settings travel with it and are checked on the way back in.

    def load_checkpoint(path: str | Path) -> Checkpoint:
    """Read a model back.

    Loads with PyTorch's safe default, which refuses arbitrary pickled objects.

    :raises CheckpointError: if the file is missing, was written by an
        incompatible format, or is one of version 0.1's pickled sessions.
    """
    path = Path(path)
    if not path.is_file():
        raise CheckpointError(f"no checkpoint at {path}")

    try:
        payload = torch.load(path, map_location="cpu", weights_only=True)
    except Exception as exc:  # noqa: BLE001 - the cause is reported verbatim
        raise CheckpointError(
            f"could not read {path}: {exc}. If this file was written by PREFFECT "
            f"0.1, it is a pickled Python object rather than a set of tensors, and "
            f"current PyTorch will not load it. Retrain, or load it with PREFFECT "
            f"0.1 under its own environment and export the weights."
        ) from exc

    if not isinstance(payload, dict) or "format_version" not in payload:
        raise CheckpointError(
            f"{path} is not a PREFFECT checkpoint: it has no format version."
        )

    found = payload["format_version"]
    if found != CHECKPOINT_FORMAT:
        raise CheckpointError(
            f"{path} is checkpoint format {found} and this is PREFFECT "
            f"{__version__}, which reads format {CHECKPOINT_FORMAT}."
        )

    config_values = dict(payload["model_config"])
    config_values["correction_variables"] = tuple(
        CorrectionVariable(**v) for v in config_values.get("correction_variables", [])
    )
    # ModelConfig coerces the enum fields back from their stored strings.
    model_config = ModelConfig(**config_values)

    gene_names = payload.get("gene_names")
    return Checkpoint(
        model_state=payload["model_state"],
        model_config=model_config,
        n_genes=int(payload["n_genes"]),
        gene_names=tuple(gene_names) if gene_names is not None else None,
        optimiser_state=payload.get("optimiser_state"),
        written_by=payload.get("written_by", "unknown"),
        format_version=found,
        extra=payload.get("extra", {}),
    )

    Inference and imputation¶

    preffect.inference ¶

    Applying a fitted model: cleaned counts, latent summaries, imputation.

    Training fits the model. Inference uses it: run data through and keep what comes out, as cleaned counts to hand to an ordinary analysis, as a latent summary to cluster in, or as filled-in values where counts were missing.

    Truth is passed in, never looked up¶

    :func:imputation_error takes the true values as an argument. It cannot find them for you, and that is the whole point.

    Version 0.1 looked for a layer called truth in the input, and if it was not there the data loader quietly made one up: the per-gene mean across samples. The error routine then compared the model against that, in a column it labelled truth_mu. On any real dataset, which carries no simulation parameters, this reported distance from the gene mean under the name of imputation accuracy, and nothing warned. That is finding 10.

    Here there is nowhere for a fabricated truth to come from. If you have no true values you cannot call the function, which is the correct outcome.

    Rows that stand in for a missing tissue are not reported¶

    The full model can be given a cohort where some patients lack the tissue it predicts. A row of per-gene means stands in for each of those patients so the rest of the cohort can be encoded, and :func:infer drops those rows from everything it returns and says how many it dropped. Reporting a cleaned count for a profile nobody measured is the sort of thing finding 10 was about.

    Inference uses the latent mean, not a draw¶

    Version 0.1 ran inference through the same path as training, which samples from the latent distribution, so running the same model over the same data twice gave different cleaned counts. Here the latent mean is used by default, so the output is deterministic and a result can be reproduced. Pass sample_latent=True for version 0.1's behaviour, which is what you want if you are deliberately drawing several times to see the spread.

        adata.obs["library_size"] = self.library_size.detach().cpu().numpy().ravel()
        adata.uns["deterministic"] = self.deterministic
        adata.uns["padded_rows_dropped"] = self.n_padded_rows_dropped
        return adata

    #: is predicted.

    recall: float

    f1: float

    #: so it needs no threshold. One when every edge outranks every non-edge.

    density: float

    #: density. The number ``average_precision`` has to beat.
    flat_average_precision: float

    #: to be edges at the threshold of one half.
    n_pairs: int
    n_edges: int

            f"among {self.n_pairs} pairs); average precision {self.average_precision:.3f} "
            f"against {self.flat_average_precision:.3f} for a flat prediction"

    @torch.no_grad()
def infer(
    model: nn.Module,
    data,
    sample_latent: bool = False,
) -> InferenceResult:
    """Run a fitted model over some data.

    Runs the whole split in one pass rather than in mini-batches: there is no
    optimiser step, so there is nothing to gain by dividing it, and batching
    would cut the sample-sample network down for no reason. See finding 22.

    :param data: a :class:`~preffect.data.tensors.TensorData` for the simple
        and single models, or a
        :class:`~preffect.data.tissues.MultiTissueData` for the full model.
    :param sample_latent: draw from the latent distribution instead of using
        its mean. Off by default, so the same model over the same data gives
        the same answer twice.
    :returns: one row per **real** sample of the predicted tissue. Where the
        full model was given a cohort with patients missing that tissue, a row
        of per-gene means stood in for each of them so that the rest of the
        cohort could be encoded; those rows are dropped here and counted in
        ``n_padded_rows_dropped``, because nothing in them was measured.
    """
    from preffect.data.tissues import MultiTissueData

    # Where the model is, the data goes. ``train`` moves its own copy of the
    # data to the device and the caller's copy stays where it was, so the
    # natural sequence of fitting on a GPU and then calling this with the same
    # data failed on a device mismatch with a PyTorch error, not a sentence.
    # Finding 45's third half.
    data = data.to(next(model.parameters()).device)

    was_training = model.training
    model.eval()
    try:
        # The library-size correction travels with the data, as the factor that
        # estimates back what hiding entries took off each sample's total. It
        # is None when nothing was hidden. For the full model it is the target
        # tissue's, since that is the only tissue whose counts are predicted.
        # Finding 56.
        real_rows = None
        if isinstance(data, MultiTissueData):
            counts = [t.inputs for t in data.tissues]
            corrections = data.target.corrections
            library_scale = data.target.library_scale
            output = model(
                counts,
                corrections,
                [t.edge_index for t in data.tissues],
                library_scale=library_scale,
            )
            target_counts = counts[0]
            # Every row goes through the model, padding included, because a
            # padded row is a node of the network the real rows attend over.
            # Only the results are cut down, below.
            real_rows = data.target_real_rows()
        else:
            corrections = data.corrections
            target_counts = data.inputs
            library_scale = data.library_scale
            if data.has_network:
                output = model(
                    data.inputs, corrections, data.edge_index, library_scale=library_scale
                )
            else:
                output = model(data.inputs, corrections, library_scale=library_scale)

        if sample_latent:
            latent = output.latent
        else:
            # Decode again from the mean, so every reported quantity comes from
            # the same latent values rather than the composition coming from a
            # draw and the summary from the mean.
            latent = output.latent_mean
            output = model._finish_counts(  # noqa: SLF001 - the model's own helper
                target_counts,
                corrections,
                latent,
                output.latent_mean,
                output.latent_log_variance,
                library_scale=library_scale,
            )
    finally:
        model.train(was_training)

    def keep(value: torch.Tensor | None) -> torch.Tensor | None:
        if value is None or real_rows is None:
            return value
        return value[real_rows]

    return InferenceResult(
        expected_counts=keep(output.expected_counts),
        composition=keep(output.composition),
        dispersion=keep(output.dispersion),
        library_size=keep(output.library_size),
        latent=keep(latent),
        zero_logits=keep(output.zero_logits),
        deterministic=not sample_latent,
        n_padded_rows_dropped=0 if real_rows is None else int((~real_rows).sum()),
    )

    def imputation_error(
    predicted: torch.Tensor,
    truth: torch.Tensor,
    hidden: torch.Tensor | None = None,
    kind: str = "mean_squared",
) -> dict[str, float]:
    """Compare filled-in values against values that are actually known.

    :param predicted: the model's expected counts.
    :param truth: the real values. **Required, and never inferred.** If you do
        not have them, you cannot measure imputation accuracy, and version
        0.1's habit of substituting the per-gene mean is why this is spelled
        out. See finding 10.
    :param hidden: boolean mask of the entries that were hidden from the model.
        When given, the error is reported separately for hidden and visible
        entries, which is the comparison that means anything: doing well on
        entries the model was shown is not imputation.
    :param kind: ``mean_squared`` or ``mean_relative``.
    :raises PreffectError: on a shape mismatch or an unknown kind.
    """
    if predicted.shape != truth.shape:
        raise PreffectError(
            f"predicted is shaped {tuple(predicted.shape)} and truth "
            f"{tuple(truth.shape)}; they have to match"
        )
    if kind not in ("mean_squared", "mean_relative"):
        raise PreffectError(
            f"kind must be 'mean_squared' or 'mean_relative', got {kind!r}"
        )

    predicted = predicted.detach().float()
    truth = truth.detach().float()

    def score(a: torch.Tensor, b: torch.Tensor) -> float:
        if a.numel() == 0:
            return float("nan")
        if kind == "mean_squared":
            return float(((a - b) ** 2).mean())
        # Relative error is undefined where the true value is zero, and count
        # data is 10 to 55 per cent zeros. Version 0.1 divided by
        # ``truth + 1e-8``, which makes a zero-truth entry contribute up to a
        # hundred million. It rarely fired there, because version 0.1 compared
        # against smoothed per-gene means rather than counts, and a per-gene
        # mean is zero only for a gene that is zero in every sample: one such
        # gene exists across the nine datasets. Comparing against actual
        # counts, which is the correct thing, makes it ordinary. Those entries
        # are left out and counted. See finding 25.
        nonzero = b != 0
        if not nonzero.any():
            return float("nan")
        return float((a[nonzero] - b[nonzero]).abs().div(b[nonzero].abs()).mean())

    if hidden is not None and hidden.shape != truth.shape:
        raise PreffectError(
            f"the mask is shaped {tuple(hidden.shape)} and truth "
            f"{tuple(truth.shape)}; they have to match"
        )
    result = {"overall": score(predicted, truth)}
    if kind == "mean_relative":
        # Counted over the entries that were scored: the hidden ones when a
        # mask is given, the whole matrix otherwise. It used to be counted over
        # the whole matrix whatever was scored (finding 53).
        scored = truth[hidden] if hidden is not None else truth
        skipped = int((scored == 0).sum())
        result["zero_truth_entries_skipped"] = skipped
        result["fraction_skipped"] = skipped / scored.numel() if scored.numel() else 0.0

    if hidden is not None:
        result["hidden"] = score(predicted[hidden], truth[hidden])
        result["visible"] = score(predicted[~hidden], truth[~hidden])
        result["n_hidden"] = int(hidden.sum())

    return result

    def network_recovery(predicted: torch.Tensor, observed: torch.Tensor) -> NetworkRecovery:
    """Score a predicted sample-sample network against the observed one.

    The loss cannot say whether the network is being recovered: on a network
    one per cent dense, a model that predicts no edge anywhere scores well on
    an unweighted cross-entropy (issue #13). This scores the edges directly.

    Both inputs are square over the same samples, the prediction a matrix of
    edge probabilities and the observation a 0/1 matrix. Both are read as
    symmetric: each pair of distinct samples is taken once, from above the
    diagonal, and the diagonal is ignored, since a sample's link to itself is
    not a pair and the loader never carries one. An edge is predicted where the
    probability exceeds one half; at exactly one half the model is undecided
    and no edge is counted, which is what the inner-product decoder produces
    when its latent has collapsed.

    Average precision is computed here rather than imported: sort the pairs by
    probability, and average the precision at each distinct probability over
    the recall it adds, which is the usual definition and treats tied
    probabilities as one threshold.

    :raises PreffectError: if the shapes differ, are not square, or the
        observed network is not symmetric.
    """
    predicted = predicted.detach().float().cpu()
    observed = observed.detach().float().cpu()
    if predicted.shape != observed.shape or predicted.dim() != 2:
        raise PreffectError(
            f"predicted is shaped {tuple(predicted.shape)} and observed "
            f"{tuple(observed.shape)}; both must be square over the same samples"
        )
    n = observed.shape[0]
    if observed.shape != (n, n):
        raise PreffectError(f"the network is shaped {tuple(observed.shape)}, not square")
    if not torch.equal(observed > 0, observed.t() > 0):
        raise PreffectError(
            "the observed network is not symmetric; the models score undirected "
            "networks, with both directions of every edge present"
        )

    rows, cols = torch.triu_indices(n, n, offset=1)
    scores = predicted[rows, cols]
    truth = observed[rows, cols] > 0
    n_pairs = int(truth.numel())
    n_edges = int(truth.sum())
    density = n_edges / n_pairs if n_pairs else 0.0

    called = scores > 0.5
    n_predicted = int(called.sum())
    hits = int((called & truth).sum())
    precision = hits / n_predicted if n_predicted else 0.0
    recall = hits / n_edges if n_edges else 0.0
    f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0.0

    if n_edges and n_pairs:
        order = torch.argsort(scores, descending=True)
        ranked_scores = scores[order]
        ranked_truth = truth[order].float()
        true_so_far = torch.cumsum(ranked_truth, dim=0)
        seen_so_far = torch.arange(1, n_pairs + 1, dtype=torch.float32)
        # The last position of each run of equal scores is one threshold; the
        # precision and recall there are what a cut at that score would give.
        last_of_run = torch.ones(n_pairs, dtype=torch.bool)
        last_of_run[:-1] = ranked_scores[:-1] != ranked_scores[1:]
        precision_at = (true_so_far / seen_so_far)[last_of_run]
        recall_at = (true_so_far / n_edges)[last_of_run]
        recall_before = torch.cat([recall_at.new_zeros(1), recall_at[:-1]])
        average_precision = float(((recall_at - recall_before) * precision_at).sum())
    else:
        average_precision = 0.0

    return NetworkRecovery(
        precision=precision,
        recall=recall,
        f1=f1,
        average_precision=average_precision,
        density=density,
        flat_average_precision=density,
        n_pairs=n_pairs,
        n_edges=n_edges,
        n_predicted=n_predicted,
    )

    def hide_entries(data, fraction: float, seed: int | None):
    """Hide a fraction of the entries at random, keeping the full counts as the targets.

    What ``--hide`` does: the model is shown counts with the hidden entries set
    to zero and scored against the originals, so its error on the hidden
    entries can be reported and watched (``TrainConfig.stop_on``). With a seed
    the same entries are hidden every time.
    """
    from dataclasses import replace

    import numpy as np
    import torch

    from preffect.data.masking import apply_mask, mcar_mask
    from preffect.data.tensors import TensorData
    from preffect.errors import ConfigError

    if not isinstance(data, TensorData):
        raise ConfigError(
            "--hide works for the simple and single models; the full model's data "
            "has one table per tissue, and hiding entries across them is not built"
        )
    counts = data.inputs.detach().cpu().numpy()
    mask = mcar_mask(counts.shape[0], counts.shape[1], fraction, np.random.default_rng(seed))
    shown = torch.from_numpy(apply_mask(counts, mask)).to(data.inputs.dtype)
    # library_scale cleared on purpose, so it is derived from the mask being
    # applied here rather than copied from whatever the data arrived with. A
    # scale given by hand wins over the mask, which is what lets a mini-batch
    # carry one, and it would silently win here too.
    return replace(data, inputs=shown, mask=mask, library_scale=None)

    def describe_network(tissue) -> str:
    """Say how many edges the network has, not merely that it exists.

    Saying "a sample-sample network" was misleading: every dataset version 0.1
    shipped carries an identity matrix there, which is a network with no edges
    at all. Someone reading that line would reasonably fit a graph model and
    get nothing for ten times the parameters. Findings 35 and 54.
    """
    import numpy as np

    from preffect.data.graph import ADJACENCY_KEY, has_adjacency

    if not has_adjacency(tissue):
        return "no network"

    matrix = tissue.obsm[ADJACENCY_KEY]
    dense = matrix.toarray() if hasattr(matrix, "toarray") else np.asarray(matrix)
    dense = np.array(dense)
    np.fill_diagonal(dense, 0)
    edges = int(np.count_nonzero(dense))

    if edges == 0:
        return (
            "a network with NO edges between samples, so the graph models "
            "have nothing to use; fit the simple model"
        )
    return f"a network with {edges // 2} edge(s), {edges / tissue.n_obs:.1f} per sample"

    """Read a split and report on it without fitting anything.

    The check the command line's ``check`` makes, as a value rather than as
    printed lines, so the interface can show the same thing. A folder that

    from preffect.data.checks import check_tissues
    from preffect.data.loading import load_tissues
    from preffect.data.tissues import unmatched_counts
    from preffect.errors import PreffectError

    folder = Path(folder)
    try:
        tissues = load_tissues(folder, n_tissues)
    except PreffectError as error:
        return SplitReport(folder=folder, tissues=(), problem=str(error))

        unmatched = unmatched_counts(tissues, split=folder.name)
    except PreffectError:
        # A correspondence table that cannot be read at all is reported by
        # check_tissues or by the alignment, with its own message. Counting is
        # the lesser question, so it gives up quietly rather than pre-empting
        # the sentence that says what is actually wrong.
        unmatched = {}
    summaries = tuple(
        TissueSummary(
            samples=t.n_obs,
            genes=t.n_vars,
            network=describe_network(t),
            unmatched=unmatched.get(f"tau_{i}", 0),
        )
        for i, t in enumerate(tissues, start=1)
    )

        check_tissues(tissues, split=folder.name)
    except PreffectError as error:
        return SplitReport(folder=folder, tissues=summaries, problem=str(error))

    def apply_checkpoint(
    model_path: Path,
    data_folder: Path,
    *,
    n_tissues: int = 1,
    device="cpu",
    report: Callable[[str], None] | None = None,
):
    """Load a saved model, read a folder of counts, and run the model over it.

    :param n_tissues: how many tissue files the folder holds. Only consulted
        if the model did not record its own count; a model saved by this
        version always does.
    :param device: where to run, as returned by
        :func:`preffect.training.resolve_device`. A string is passed to
        PyTorch as it is; resolve it first if it might name a device the
        machine lacks.
    :param report: called with each progress line; leave unset for silence.
    :returns: the :class:`~preffect.inference.InferenceResult`, the tissues it
        was computed on with their genes already matched to the model's, and
        the checkpoint. Where the full model was given a cohort with patients
        missing the predicted tissue, the rows padded in for them are dropped
        from the result **and** from the first tissue returned, so the two
        still line up row for row.
    """
    from preffect.checkpoint import load_checkpoint
    from preffect.data.selection import GeneSelection, apply_gene_selection
    from preffect.data.tissues import ghost_rows
    from preffect.inference import infer

    def say(line: str) -> None:
        if report is not None:
            report(line)

    data_folder = Path(data_folder)
    checkpoint = load_checkpoint(model_path)
    say(
        f"loaded a {checkpoint.model_config.kind.value} model written by PREFFECT "
        f"{checkpoint.written_by}, applying on {device}"
    )

    n_tissues = int(checkpoint.extra.get("n_tissues", n_tissues))
    kind = checkpoint.model_config.kind
    model = build_model(kind, checkpoint.n_genes, checkpoint.model_config, n_tissues)
    model.load_state_dict(checkpoint.model_state)
    model.to(device)

    tissues = read_split(data_folder, n_tissues)
    if checkpoint.gene_names is not None:
        # Match the genes the model was fitted on, by name. Without this a
        # column could mean a different gene than it did during training,
        # which is finding 18.
        selection = GeneSelection(names=checkpoint.gene_names, basis="from the model")
        tissues = apply_gene_selection(tissues, selection, data_folder.name)
        say(f"matched {len(selection)} genes to the ones the model was fitted on")

    data = to_model_data(tissues, checkpoint.model_config, kind.uses_adjacency).to(device)
    result = infer(model, data)
    if result.n_padded_rows_dropped:
        say(
            f"dropped {result.n_padded_rows_dropped} row(s) that were padded in "
            f"for patients with no sample in the predicted tissue; nothing in "
            f"them was measured"
        )
        real = ~ghost_rows(tissues[0])
        tissues = [tissues[0][real].copy(), *tissues[1:]]
    return result, tissues, checkpoint
